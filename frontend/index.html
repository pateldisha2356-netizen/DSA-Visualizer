How this project is wired together

Sorting, Searching, and Graphs call a real REST API (/api/sort, /api/search, /api/graph) served by the Spring Boot app in /backend — start it with mvn spring-boot:run before opening those pages. Linked List and Trees run entirely in this page's JavaScript, since the backend doesn't expose endpoints for them yet.
